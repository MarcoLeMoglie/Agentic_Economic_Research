# Teaching

Courses, lecture material, syllabi, grading notes, and supervision.

## Projects

_No projects yet._ Teaching projects are created when a concrete course or supervision case starts; an empty placeholder project would only add noise.

## Adding a project

```bash
bash .infra/scripts/new-project.sh Teaching <slug> "<Title>"
```

Then register it here and in [general/MEMORY.md](../../general/MEMORY.md). Course-specific raw material (slides, readings, exam texts) goes in that project's `raw/`, not in this index.

## Area conventions

- Do not store student personal data, grades, or identifying material in the vault.
- Course structure and learning objectives are stable: good candidates for a project `wiki/` page once they exist.
- Reusable teaching procedures (e.g. exam design, feedback workflow) belong in [general/capabilities/skills/](../../general/capabilities/skills/).
