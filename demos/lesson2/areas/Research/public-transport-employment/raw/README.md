# raw/ — Original Sources

Files here are **originals or faithful captures**. They are read-only for this project: never edit, reformat, or "clean" them. If a cleaned version is needed, create a derived file outside `raw/` and name the transformation.

## Naming

`YYYY-MM-DD-short-slug.ext` — e.g. `2026-11-10-concept-note.md`.

## Each capture needs a provenance header

```markdown
> **PROVENANCE**
> Type: memo / paper / dataset / email / web capture
> Author or publisher:
> Date:
> Acquired: YYYY-MM-DD
> Locator / URL:
> Synthetic: yes / no
> Notes:
```

For PDFs and data files, record the same metadata in [SOURCES.md](../SOURCES.md) instead of editing the file.

## Rules

1. Register every file in [SOURCES.md](../SOURCES.md) with an ID (`S-xxx`).
2. Mark fictional or illustrative material **SYNTHETIC** in the first line.
3. Do not add secrets, personal data, or copyrighted material you are not allowed to store.
4. Do not rename a source after it has been cited; add a new capture instead.
5. Keep the file small enough to be inspectable. Large binaries are acceptable only when the source cannot be captured as text.
