# Lesson 3 — Automations and Control

30 slides. Theme is `lesson2/preamble.tex`, which loads `lesson1/preamble_v2.tex`.

## Compile

1. Set the Overleaf main document to `main.tex`.
2. Leave `\input{lesson3/lesson3.tex}` as the only active line.
3. Compiler: pdfLaTeX.

Local check from the repo root: `mkdir -p /tmp/l3 && tectonic --outdir /tmp/l3 main.tex`.
