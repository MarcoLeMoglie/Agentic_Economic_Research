# Lesson 3 — Automations and control

`lesson3.tex` is the whole deck. It uses `lesson2/preamble.tex`.

## Compile

1. Set the Overleaf main document to `main.tex`.
2. Leave `\input{lesson3/lesson3.tex}` as the only active line.
3. Compiler: pdfLaTeX.

From the repo root: `mkdir -p /tmp/l3 && tectonic --outdir /tmp/l3 main.tex`.
